# Pharma Sales & Inventory Analysis | Power BI

## Project Overview
An end-to-end Power BI project analyzing pharmaceutical sales, returns, and inventory performance.

## Key Areas of Analysis
- Sales Performance Analysis
- Return Analysis
- Inventory & Expiry Monitoring
- Product and Category Performance
- Business Insights & Recommendations

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling

## Business Focus
The project focuses on identifying business challenges, understanding return reasons, monitoring inventory risks, and providing actionable recommendations to improve sales and inventory management.
